# ScopeGraph film directions

The requested film is produced without a decision pause. The selected direction is **One requirement, many consequences** because the same email-change requirement can travel from the initial concern through a real graph and source-backed report.

1. **One requirement, many consequences — selected.** A single change request expands into routes, services and tests. The film cuts between the real ScopeGraph workspace and a clearly illustrative dependency line, ending on source evidence. Look: ink, warm white, restrained lime; real application captures remain unaltered. Sound: measured English narration when a licensed recording is available.
2. **The evidence trail.** Start on a line of source code, trace outward through the graph and reconstruct how the report came to that line. Look: code editor scale and architectural white space. Sound: sparse clicks and voice.
3. **Two views of a change.** Split screen between a UI request and the codebase that must respond; the halves converge at validated evidence. Look: modular panes using ScopeGraph’s own interface colors. Sound: editorial voice and quiet percussion.

The first frame shows a concrete file and its dependent path. The selected film then uses the repository-owned sample and authentic README captures; it labels illustrative or offline material on screen.
