# ScopeGraph hackathon film specification

GOAL: Judges understand that ScopeGraph proposes likely change impacts while validating cited code locations against an index.

OUTPUT: Editable HyperFrames composition, 1920 × 1080, 30 fps, 180 seconds maximum.

TIME: Eight scenes at 0, 15, 35, 60, 95, 115, 135 and 160 seconds. Hard cut or short overlap at boundaries; no scroll simulation that implies a UI action.

LOOK: `#151923` ink, `#F7F8F5` warm white, `#C7F36B` lime only on the active focus; `#526BEE` for a verified graph path; `#E5484D` for direct and `#F5A623` for indirect risk. Inter 700 at 80–112 px for headings, Inter 400 at 35–46 px for explanations, JetBrains Mono 28–34 px for code labels. Screenshots keep their original pixels and colors. No glow, grain, vignette or made-up product chrome.

OBJECTS: One real sample requirement, the actual sample repository graph capture, the actual offline impact and evidence capture, the owned synthetic email-settings PNG, the actual screenshot attachment capture, a clearly conceptual UI proposal, a source-backed architecture diagram, and the official ScopeGraph SVG mark.

MOTION: One dominant move per shot. Entrance 12–20 frames, connected path draw 30–50 frames, image pan 24–36 frames, hold for reading. Eases `power2.out` and `power2.inOut`; no springs. No continuous idle motion. Each scene contains at least two changes separated by a reading hold.

SHOTS: 0–450 hook/illustrative dependency growth; 450–1050 real product and premise; 1050–1800 real indexed sample graph; 1800–2850 actual offline report and evidence; 2850–3450 screenshot input and the documented one-call Meta vision observation; 3450–4050 offline UI proposal, explicitly conceptual; 4050–4800 Meta-oriented architecture and MCP, with optional providers marked unverified; 4800–5400 source-backed result to GitHub/wordmark.

BANNED: Generated dashboard, invented metrics, fake live provider output, unmarked mock data, stock AI imagery, purple gradients, floating cards without source context, tiny full-page screenshots, long static slides, implied live full-pipeline Meta vision result.

QA: Inspect frames at 0, 1, 8, 15, 35, 60, 77, 94, 95, 115, 135, 160, 175 and all scene seams. Confirm offline and conceptual labels are legible. Confirm real screenshot crops do not hide source paths when the narration discusses evidence. Verify 180.0 s maximum and 30 fps in the rendered MP4.
