# Video submission handoff

- [ ] Review all eight scenes in the HyperFrames preview and watch the complete exported MP4 on a second player.
- [ ] Record a licensed human English voice-over using [the timed script](VIDEO_SCRIPT_3MIN_EN.md); mix it with the film and align [the SRT](VIDEO_SUBTITLES_EN.srt) to actual spoken words.
- [ ] If replacing the screenshot sequence with screen recording, record the local sample repository only, hide credentials, and retain the **offline** provider disclosure unless a new authorized live run is captured.
- [ ] Obtain a fresh, approved full-pipeline Meta result before presenting Screenshot-to-Impact as live end-to-end Meta behavior.
- [ ] Verify the current local UI Proposal V2 in a browser before replacing its conceptual illustration with product footage.
- [ ] Review every source/asset attribution in [MEDIA_ASSET_MANIFEST.md](MEDIA_ASSET_MANIFEST.md).
- [ ] Confirm the hackathon portal’s current length, file, licensing, disclosure and deadline requirements; the three-minute target is a production brief, not an asserted official rule.
- [ ] Upload the approved video manually, insert the actual public URL into `docs/HACKATHON_SUBMISSION.md`, and check judge access.

No publication, upload, commit or push is performed by this production task.
